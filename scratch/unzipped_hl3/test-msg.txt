2. **Why Maintenance Mode automatically turns off**: This happens because the application is running in a serverless container environment. The database (`admin_db.json`) is stored on the local filesystem. When your phone screen turns off and no one is actively using the app, the server goes to sleep to save resources. When you wake it up again, it spins up a fresh container and the filesystem is reset to its original state (the code in the repository), which had `maintenanceMode: false`. 

To prevent settings from resetting when the server sleeps, we need to either:
- Set it to `true` by default in the code (which I have just done).
- Migrate your database from local JSON files to a persistent cloud database (like Firebase or PostgreSQL) so that admin dashboard changes are saved permanently.
